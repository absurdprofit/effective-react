# Installation
```
# deno, pnpm 10.9+, and yarn 4.9+ with first class JSR support
deno add jsr:@absurdprofit/effective-react
pnpm add jsr:@absurdprofit/effective-react
yarn add jsr:@absurdprofit/effective-react

# npm, bun, and older versions of yarn or pnpm
npx jsr add @absurdprofit/effective-react
bunx jsr add @absurdprofit/effective-react
yarn dlx jsr add @absurdprofit/effective-react
pnpm dlx jsr add @absurdprofit/effective-react
```
